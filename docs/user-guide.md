# 飞售零售管理系统（RMS）项目说明与使用手册

版本：v1.0

## 1. 项目简介

飞售零售管理系统面向连锁零售/便利店场景，覆盖门店、商品（SKU/条码）、会员（等级折扣+积分+储值）、促销（满减/折扣）、POS 收银、库存（批次/效期/FEFO）、采购、供应商、财务与风险十大业务域，预留标准 API 供电商/外卖/支付网关对接。

- 访问地址：`http://42.193.158.63/retail/`（生产）｜ 本地 `http://127.0.0.1:8029`
- 技术栈：Python 标准库 + SQLite（零依赖）+ 原生 JS SPA

## 3. 页面导览（13 页）

1. **工作台**：今日营收/销售/会员/促销、待收货、低库存、临期、未处理风险
2. **门店管理**：门店编码/地址/状态
3. **商品管理**：SKU、EAN 条码扫码查询、售价/进价、保质期、安全库存、CSV 导出
4. **会员管理**：等级（普通/银卡95/金卡9/铂金85折）、积分、储值、充值
5. **促销活动**：满减（满 X 减 Y）与折扣（88 折）；时间窗/门店冲突校验
6. **POS 收银**：选门店/会员 → 加商品 → 结账（现金/微信/支付宝/储值）；自动匹配最优促销 + 会员折扣 + 积分
7. **销售单据**：明细（小计/促销优惠/会员优惠/实收）、退货（库存回补+积分冲减+负流水）
8. **库存管理**：门店×商品×批次、效期、临期标识
9. **采购管理**：草稿→提交→入库（入批次库存+应付）
10. **供应商**：账期、应付、欠款上限
11. **财务流水**：收入/退款/采购支出、支付方式分布
12. **风险预警**：低库存/临期/负毛利/欠款超限四类扫描与处理
13. **系统管理**：用户、公告、API Key、增量同步状态

## 4. 典型业务流程

### 4.1 POS 收银
门店 → （可选会员）→ 加商品（扫码/选择）→ 结账选支付方式 → 系统自动：促销最优匹配 → 会员折扣 → FEFO 扣库存 → 发积分 → 现金找零。

### 4.2 补货
采购管理新建单（供应商/门店/商品/批次/效期）→ 提交 → 入库确认 → 库存即时增加、供应商应付累加。

### 4.3 退货
销售单据 → 退货 → 库存回补、积分冲减、退款负流水，单据状态变「已退货」。

## 5. 与外部系统对接

- 五通道鉴权：Bearer / X-Token / Cookie / ?token= / X-Api-Key
- 幂等：写接口带 `Idempotency-Key` 头重复请求安全重试
- 增量同步：`GET /api/sync?since=<ver>&entities=commodities,sales,...`
- CSV 导出：`GET /api/export/<entity>?format=csv`
- 完整契约见 `docs/api.md`（82 条路由）

