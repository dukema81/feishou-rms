## 4. 关键验证点（抽样）

### 4.1 计价链路（手算对照）
- 无会员散客：可乐 5×350 + 山泉 5×200 = 2750 分；88 折优惠 330 分；实付 2420
- 银卡会员：2750 − 330（88折优于满减）= 2420 × 0.95 = 2299 分 ✅
- 试算接口：1350 → 88 折 −162 → gold 0.9 实付 1069（HALF_UP 1069.2→1069）✅

### 4.2 FEFO 与库存一致性
- 销售按效期近先出扣批次；库存不足整体失败 422 不半扣 ✅
- 退货库存回补（+qty 核对）、二次退货 422 ✅

### 4.3 业务规则
- 储值余额不足 422；余额支付扣减并留痕 member_txns ✅
- 条码重复 409；促销时间窗重叠 422；非法状态流转 422 ✅
- 负毛利销售不阻断但生成 negative_margin 风险 ✅
- 采购 receive 入批次库存 + 供应商应付累加 + 欠款超限风险 ✅
- 角色权限：收银员禁触风险/采购（403）、只读账号禁写（403）、ApiKey X-Api-Key 通道 ✅
- 幂等：同 Idempotency-Key 返回同一销售单号 ✅

## 5. 缺陷与修复记录

| # | 缺陷 | 修复 |
|---|---|---|
| 1 | 风险扫描 SQL 误用 s.store_id（主键为 id）500 | 改 s.id AS store_id |
| 2 | seed 手工插入会员/商品编码未同步 seq → 建档 UNIQUE 冲突 500 | seed 显式初始化 member_code=4、commodity_sku=8 |
| 3 | DELETE /api/users/{id} 路由缺失 404 | 补 h_users_delete（禁自删、清理 token） |
| 4 | 冒烟 JSON 解析 CSV 导出遇 BOM 异常 | req 改 utf-8-sig + 非 JSON 原样返回 |
| 5 | 冒烟促销与种子促销时间窗重叠误报 | 冒烟促销指定独立门店 |
